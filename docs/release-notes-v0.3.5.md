# v0.3.5 Release Notes（草稿：发布时直接贴到 GitHub Release 描述）

## 新增

- **打包即体检**：`npm run build` / `npm run build:dir` 打包完成后自动运行 `verify:smoke`
  五步冒烟验证——离线单测 24 项、静态守卫检查、Node 侧车启动、成品 exe 启动、
  安装器端到端（静默安装 → 启动 → 监听 → 卸载 → 还原快捷方式）。任一步失败即报红，
  "装上打不开"的产物发不出去。
- 冒烟验证全程使用临时数据目录（`DSH_HOME` 隔离），不触碰用户真实会话与凭据；
  本机有正式实例运行时自动跳过安装器环节，互不干扰。

## 修复

- **修复构建机在新 Node 环境下打包必然失败的问题**（Node 24 安全加固后禁止直接调用
  `.cmd` 脚本，表现为依赖安装静默报错、无任何输出）。仅影响构建过程，不影响已安装用户。
- 构建失败时现在会输出真实错误原因（此前诊断信息被吞，只显示空错误）。

## 文档

- 分发说明与现实对齐：移除"侧车含 npm"的错误描述；"检查 dsh 更新"如实标注为
  暂不可用（侧车无 npm，待免 npm 实现）；文件名改为实际产物名；版本信息翻到 0.3.5。

## 升级方式

- 安装版：托盘「检查桌面端更新」自动下载安装；或从 Releases 下载
  `DS Harness Desktop Setup 0.3.5.exe` 覆盖安装。
- 便携版：从 Releases 重新下载 `DS Harness Desktop-0.3.5-portable.exe` 替换旧文件。

## 已知限制

- 应用内「检查 dsh 更新」暂不可用（后续版本以免 npm 方式实现，见项目 NEXT 待拍板项）。
- 便携版无法原地自更新（既有限制）。
