# DS Harness Desktop 分发说明

> 面向「要把桌面版发给别人」的分发者。适用 v0.3.5（Windows）。

## 1. 发什么：一个文件即可

| 推荐 | 文件（从 [Releases](https://github.com/ljr282341583/ds-harness-desktop/releases) 下载，或自行构建后在 `产出\`） | 说明 |
|---|---|---|
| ✅ 首选 | `DS-Harness-Desktop-Setup-0.3.5.exe` | 安装版，向导安装（可自选安装目录），带开始菜单/卸载入口；**收到新版能自己更新** |
| 可选 | `DS-Harness-Desktop-0.3.5-portable.exe` | 免安装单文件，双击即用，适合随意拷贝（但需手动更新） |

- 二选一即可，**不要两个都发**（内容一样；v0.3.4 起单个约 130 MB，此前约 213 MB）。
  注意：Releases 上的资产名是**连字符**形态（electron-builder 发布时自动规范化，
  自更新清单 latest.yml 也按该名下载），而本地 `产出\` 落盘文件名带空格——二者是同一文件。
- 单文件里已自带 Electron、Node 24 侧车、dsh 及全部依赖，对方**无需安装任何运行时**（侧车不含 npm，见下表"检查 dsh 更新"说明）。
- 把 Releases 页面链接直接发给对方更省事：让对方自己挑形态下载，也方便他以后自己更新。

### 两种形态的更新能力差异

| 形态 | 检查 dsh 更新 | 检查桌面端更新 |
|---|---|---|
| 安装版（Setup） | ⚠️ 暂不可用（侧车无 npm，待免 npm 实现；dsh 升级请随桌面端整体更新） | ✅ 下载后重启安装（v0.3.2 起） |
| 便携版（portable） | ⚠️ 暂不可用（侧车无 npm，待免 npm 实现；dsh 升级请随桌面端整体更新） | ⚠️ 无法原地替换自身，需手动下载新文件替换 |

> 想把"桌面端自身也能自动更新"作为体验卖点，就分发**安装版**；
> 想追求"免安装、可随意拷贝"，就用便携版，但要接受它需要手动更新。
>
> 说明：自动更新会复用首次安装时选定的目录；如果你的机器上出现过"更新后打不开"，
> 重新运行一次安装包即可修复（见 `docs\使用方法.md` 的常见问题）。

## 2. 不要发这些

| 文件/目录 | 原因 |
|---|---|
| `win-unpacked\` | 零散文件 + 与 portable 重复 |
| `app\`、`runtime\`、`build\` | 源码与构建材料，对方用不到 |
| `过程记录\`、`docs\`、`README.md` | 项目内部资料 |
| `latest.yml`、`*.blockmap` | 是给「桌面端自更新」用的清单与差分文件，发布在 Release 里即可，不要单独发给别人 |

## 3. 对方需要自行准备 3 件事

1. **Windows 10/11 64 位**（Electron x64）。Mac/Linux 不支持（v1 仅 Windows）。
2. **自己的 DeepSeek API Key**：桌面版不捆绑任何密钥，复用对方机器的 `~\.dsh`。
   新机器首次打开后，在界面 **Settings → Models** 填自己的 key（与 web 版一致）。
3. **首次可能被 SmartScreen 拦**（v1 未签名，且经微信/网盘/邮件下载会带「来自
   Internet」标记）。让对方点「**更多信息 → 仍要运行**」即可。

## 4. 减少 SmartScreen 干扰的两种办法

- 让对方：右键 exe → 属性 → 底部勾选「**解除锁定**」→ 确定，再运行。
- 长期方案：拿到代码签名证书后给 exe 签名（见 `docs\设计方案.md` 的后续项），
  可彻底消除「未知发布者」提示。

## 5. 一句话发给对方

> 双击运行；Settings 里填你自己的 DeepSeek API Key；被 Windows 拦就点「更多信息 → 仍要运行」。
