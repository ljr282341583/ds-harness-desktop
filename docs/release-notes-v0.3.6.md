# v0.3.6 Release Notes（草稿：发布时直接贴到 GitHub Release 描述）

## 新增

- **更新反馈三件套**：下载完成弹出对话框，「立即重启并安装」一键直达；下载失败不再
  无声无息（弹窗提示）；下载中 busy 文案改为「正在下载桌面端 vX…」。进度反馈保留
  任务栏进度条与托盘悬停百分比——更新全程看得见。
- **本地打包自动补齐侧车运行时**：`npm run build` / `npm run build:dir` 现在自动先跑
  `prepare-runtime.ps1`（Node 侧车与 npm 已就绪时秒过、不重复下载），本地产物与 CI
  发布物一致，不再依赖"记得手动先跑脚本"。
- **打包门禁新增「侧车含可执行 npm」断言**：静态检查会真实执行侧车
  `node npm-cli.js --version`，缺 npm 的构建直接报红、发不出去——这是应用内
  「检查 dsh 更新」的前提，防止 prepare-runtime 被绕过后回归。

## 修复

- **应用内「检查 dsh 更新」恢复可用**：经核实 GitHub 发布物的侧车本就包含 npm
  （此前文档方向误判为不可用）；配合上一条门禁断言，该能力从"看运气"变成"有保障"。

## 文档

- 分发说明按 0.3.5 实测改写更新目录行为（更新向导保持全机模式、记忆键回填 G:\）。
- README 对齐 0.3.5 发版状态：下载表、体检命令、发布示例、当前状态与变更记录。
- 补入 2 篇历史过程记录（2026-08-23 dsh 升级 0.1.1-rc.2 与版本快照）及会话档案
  身份审计脚本。

## 升级方式

- 安装版：托盘「检查桌面端更新」自动下载安装；或从 Releases 下载
  `DS-Harness-Desktop-Setup-0.3.6.exe` 覆盖安装。
- 便携版：从 Releases 重新下载 `DS-Harness-Desktop-0.3.6-portable.exe` 替换旧文件。
- 升级弹出向导时**保持默认「全机」模式、不要切换「仅当前用户」**（切错会产生双安装 /
  孤儿安装）；升级后可查看 `resources\app\package.json` 确认版本为 0.3.6。

## 已知限制

- 便携版无法原地自更新（既有限制，需手动下载新文件替换）。
- 桌面端运行期间，打包体检的「安装器端到端」一步会自动跳过（防止按进程名误杀正在
  使用的窗口）；其余四步体检全绿才会产出交付物。
