# DS Harness Desktop 使用方法

> 适用版本：v0.1.1（Windows）｜ 本文面向最终使用者。

## 1. 这是什么

DS Harness Desktop 是 DeepSeek Harness（`dsh`）的桌面版：把原本在浏览器
`http://127.0.0.1:3080` 使用的 web 界面，装进独立的 Windows 窗口 + 系统托盘，
后端能力（会话、工具、settings、subagent、workflow 等）与 web 版完全一致。

## 2. 启动（四选一）

| 方式 | 做法 | 适用场景 |
|---|---|---|
| 桌面版（已复制到桌面） | 双击桌面 `DS Harness Desktop.exe` | 日常最方便 |
| 便携版 | 双击 `产出\DS Harness Desktop-0.1.1-portable.exe` | 免安装、可随意拷贝 |
| 安装版 | 双击 `产出\DS Harness Desktop Setup 0.1.1.exe` 按向导安装，再从开始菜单/桌面快捷方式打开 | 需要开始菜单/卸载入口 |
| 免安装目录 | 双击 `产出\win-unpacked\DS Harness Desktop.exe` | 最原始、启动最快 |

> 四种方式功能完全一样，只是打包形态不同。自用推荐第 1、2 种。

## 3. 首次启动你会看到什么

1. 先出现「正在启动 DeepSeek Harness…」加载页（约 3~5 秒，后台在拉起 dsh）。
2. 自动加载出 DSH 的 web 界面（会话、工具、settings 全套）。
3. 右下角出现系统托盘图标（DSH 蓝标）。

> **关键**：桌面版复用 `C:\Users\Administrator\.dsh`，已有的 API 密钥、会话、
> skills、profiles 全部直接可用，**无需重新配置**。

## 4. 日常操作

| 操作 | 怎么做 |
|---|---|
| 关窗口但不退出 | 点窗口右上角 ✕ → 最小化到托盘，后台常驻 |
| 从托盘唤回窗口 | 单击托盘图标（或右键 → 显示窗口） |
| 真正退出 | 托盘右键 → **退出**（会一并干净结束 dsh 子进程） |
| 服务卡死/异常 | 错误页点「重启服务」，或托盘右键 → 重启服务 |
| 端口/已有实例 | 若 3080 已有 DSH 在跑（如网页版），桌面版**直接复用它**，不再新开实例 |
| 重复启动 | 只聚焦已有窗口（单实例），不会开两个 |

## 5. 注意事项

- **SmartScreen**：因 v1 未做代码签名，从本机直接双击一般不会拦；若复制给别人
  或换机器下载后首次运行弹「未知发布者」，点「更多信息 → 仍要运行」即可。
- **与浏览器版同开**：桌面版会检测 3080 是否已有 DSH（网页版）在跑，有就直接
  复用、显示同一个界面，**不会再开第二个实例**（避免两个实例并发读写 `~/.dsh`
  导致会话/项目列表异常）。所以「先开网页版再开桌面版」= 桌面版只是网页版的
  一个窗口，数据完全一致。
- **工作目录**：桌面版自己拉起 dsh 时，默认在「用户主目录」下工作；可用环境
  变量 `DSH_DESKTOP_CWD` 指定工作目录（workspace 根）。想直接在 `AI工作空间`
  下工作，建议先开网页版（让桌面版复用它），或设置 `DSH_DESKTOP_CWD`。
- **退出确认**：托盘「退出」后，任务管理器里不应再有 `DS Harness Desktop.exe`
  及其对应的 `node.exe`（dsh 子进程）。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 一直停在「正在启动…」 | 可能是 dsh 首次初始化较慢，等 10~30 秒；仍不行则托盘「重启服务」 |
| 显示「服务不可用」 | 点页面「重启服务」按钮，或托盘「重启服务」 |
| 端口 3080 已有 DSH | 无需处理，桌面版会自动复用那个实例；若 3080 是别的程序占着，才会用 3081+ |
| 窗口关了找不到 | 它在托盘里，单击托盘图标唤回 |
