# DS Harness Desktop 使用方法

> 适用版本：v0.3.4（Windows）｜ 本文面向最终使用者。

## 1. 这是什么

DS Harness Desktop 是 DeepSeek Harness（`dsh`）的桌面版：把原本在浏览器
`http://127.0.0.1:3080` 使用的 web 界面，装进独立的 Windows 窗口 + 系统托盘，
后端能力（会话、工具、settings、subagent、workflow 等）与 web 版完全一致。

## 2. 启动（四选一）

| 方式 | 做法 | 适用场景 |
|---|---|---|
| 桌面版（已复制到桌面） | 双击桌面 `DS Harness Desktop.exe` | 日常最方便 |
| 安装版 | 从 [Releases](https://github.com/ljr282341583/ds-harness-desktop/releases/latest) 下载 `DS-Harness-Desktop-Setup-0.3.4.exe`，按向导安装（可自选安装目录）后从开始菜单/桌面快捷方式打开 | 需要开始菜单/卸载入口；**支持托盘自更新** |
| 便携版 | 从 Releases 下载 `DS-Harness-Desktop-0.3.4-portable.exe`，双击即用 | 免安装、可随意拷贝；无法原地自更新 |
| 免安装目录 | 双击本地构建产物 `产出\win-unpacked\DS Harness Desktop.exe` | 从源码构建后直接跑，启动最快 |

> 功能完全一样，只是打包形态不同。自用推荐安装版（能自动更新）或便携版（免安装）。

## 3. 首次启动你会看到什么

1. 先出现「正在启动 DeepSeek Harness…」加载页（后台在拉起 dsh）。
   冷启动需要初始化 profile，通常十几秒；首次使用或刚换到新 dsh 版本时可能到一分钟，属正常现象。
2. 自动加载出 DSH 的 web 界面（会话、工具、settings 全套）。
3. 右下角出现系统托盘图标（DSH 蓝标）。

> **关键**：桌面版复用 `C:\Users\Administrator\.dsh`，已有的 API 密钥、会话、
> skills、profiles 全部直接可用，**无需重新配置**。

## 4. 日常操作

| 操作 | 怎么做 |
|---|---|
| 关窗口但不退出 | 点窗口右上角 ✕ → 最小化到托盘，后台常驻 |
| 从托盘唤回窗口 | 单击托盘图标（或右键 → 显示窗口） |
| 真正退出 | 托盘右键 → **退出**（会一并干净结束 dsh 子进程） |
| 服务卡死/异常 | 错误页点「重启服务」，或托盘右键 → 重启服务 |
| 端口/已有实例 | 若 3080 已有 DSH 在跑（如网页版），桌面版**直接复用它**，不再新开实例 |
| 重复启动 | 只聚焦已有窗口（单实例），不会开两个 |

## 4.1 更新（托盘右键）

托盘里有两个不同的更新入口，分别管两层：

| 菜单项 | 更新对象 | 说明 |
|---|---|---|
| **检查 dsh 更新** | 官方 DeepSeek Harness 本体 | 发现新版后可一键下载并切换，**不需要重新安装桌面端** |
| **检查桌面端更新** | 桌面端程序自身（外壳） | 检查 → 下载 → 重启并安装新版本 |

相关菜单项：

| 菜单项 | 作用 |
|---|---|
| 更新通道 | `官方推荐（stable）` 跟官方 latest 标签；`尝鲜（preview）` 跟 next 标签 |
| 回到内置版本 | 把 dsh 切回随安装包捆绑的版本；不想用新版本时用它 |
| 打开数据目录 | 打开应用数据目录（含已下载的 dsh 版本与日志） |

行为需知：

- **dsh 更新是安全的**：新版本会先通过启动冒烟验证才启用；任一步失败都会保留原版本。
  若新版本装了却启动不起来，程序会自动回退到内置版本并重启一次。
- **不影响你的数据**：更新全程只写入应用自己的数据目录，不触碰 `~/.dsh`
  里的密钥、会话、skills 与 profiles。
- **磁盘占用**：只保留当前版本与上一个可用版本，其余自动清理。
- **便携版差异**：便携版（单文件 exe）每次启动都会自解压到临时目录，无法在原地
  替换自己，因此「检查桌面端更新」会引导你从发布页下载新的便携版文件替换旧文件。
  安装版可直接重启安装。**dsh 本体的更新在两种版本上都能用。**
- **首次更新较慢**：需要联网下载依赖（约几分钟，视网络而定），期间托盘提示会显示进度。
- **「稍后」的含义**：桌面端更新下载完后选「稍后」会暂不安装；托盘里会出现「重启并安装 vX」，
  想装时点它（安装前会先干净停掉 dsh 服务，避免装坏）。

## 5. 注意事项

- **SmartScreen**：因 v1 未做代码签名，从本机直接双击一般不会拦；若复制给别人
  或换机器下载后首次运行弹「未知发布者」，点「更多信息 → 仍要运行」即可。
- **与浏览器版同开**：桌面版会检测 3080 是否已有 DSH（网页版）在跑，有就直接
  复用、显示同一个界面，**不会再开第二个实例**（避免两个实例并发读写 `~/.dsh`
  导致会话/项目列表异常）。所以「先开网页版再开桌面版」= 桌面版只是网页版的
  一个窗口，数据完全一致。
- **工作目录**：桌面版自己拉起 dsh 时，默认在「用户主目录」下工作；可用环境
  变量 `DSH_DESKTOP_CWD` 指定工作目录（workspace 根）。想直接在 `AI工作空间`
  下工作，建议先开网页版（让桌面版复用它），或设置 `DSH_DESKTOP_CWD`。
- **退出确认**：托盘「退出」后，任务管理器里不应再有 `DS Harness Desktop.exe`
  及其对应的 `node.exe`（dsh 子进程）。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 一直停在「正在启动…」 | dsh 首次初始化可能较慢，等 10~60 秒；仍不行则托盘「重启服务」 |
| 显示「服务不可用」 | 先点页面「重启服务」按钮。若反复出现，多半是 `~\.dsh\profiles` 里的第三方插件与当前 dsh 版本不兼容（dsh 会启动即退出）；查看 `%APPDATA%\ds-harness-desktop\dsh-child.log`，日志会指明是哪个插件，临时办法是先在 profile 里移除它 |
| 检查更新显示已是最新 | `stable` 通道跟官方 `latest` 标签；官方未提升该标签时就会显示已是最新。想尝鲜可切到 `preview` |
| **更新后应用打不开** | 从 [Releases](https://github.com/ljr282341583/ds-harness-desktop/releases/latest) 重新下载最新安装包再装一次即可修复（只覆盖程序文件，不动 `~/.dsh`）。v0.3.1 的自动更新曾出现装坏的情况，v0.3.2 已修 |
| 端口 3080 已有 DSH | 无需处理，桌面版会自动复用那个实例；若 3080 是别的程序占着，才会用 3081+ |
| 窗口关了找不到 | 它在托盘里，单击托盘图标唤回 |

## 7. 版本与产物位置

- 源码：`app\`（Electron 壳）
- 安装包/便携版：优先从 [GitHub Releases](https://github.com/ljr282341583/ds-harness-desktop/releases) 下载；自行构建的产物在 `产出\`
- 运行日志：`%APPDATA%\ds-harness-desktop\dsh-desktop.log`（外壳）与 `dsh-child.log`（dsh 输出）
- 设计文档：`docs\设计方案.md`
- 分发给他人的说明：`docs\分发说明.md`
