# 2026-09-25 手机访问中继内置到桌面端（v0.3.8）

## 起因

手机端（`ds-harness-mobile`）连电脑，原本要另开一个黑窗口跑配对脚本
（`tools/dsh-mobile-pair.mjs`），并且**那个窗口必须一直开着**——关掉手机就断。
用户提出：打开桌面端就自动起中继、关掉就结束，不要再管窗口。

## 做了什么

- **中继跑进主进程**（`app/src/relay.js`）：把"手机够得着的尾网地址"接到 `127.0.0.1:<dshPort>`。
  改写 `Host`/`Origin`/`Referer` 以穿过 dsh 的 `/api` 信任围栏；**认证仍由官方启动令牌 + cookie
  负责**，中继不持有任何凭据。因为它就在主进程里，**随 App 生死，不存在孤儿进程**。
  移植 `ds-harness-mobile/tools/dsh-mobile-relay.mjs` 的两条实测经验：
  ① 客户端断开（刷新/切后台）不得让进程崩掉；② 未认证的 WebSocket 升级必须原样回 401，
  否则浏览器表现为"无限转圈"。
- **起停挂点**（`app/src/main.js`）：`startHarness()` 里 spawn 完 dsh 就起中继（中继只依赖
  `dshPort`，不需要令牌）；`stopHarness()` 与 `will-quit` 里收掉。`dsh:restart` 走同一条路径。
- **尾网地址探测**（`app/src/tailnet.js`）：`tailscale status --json` → 失败则扫网卡找
  `100.64.0.0/10`；都没有就不启动并在托盘显示人话原因（不静默失败）。**只绑尾网地址**。
- **扫码配对**：`app/src/qr-png.js`（自写 PNG 编码，`zlib` + 自算 CRC32）+ `app/src/vendor/
  qrcode-generator/`（MIT，唯一第三方代码）+ `app/src/pair-qr.html`（二维码小窗，含"复制地址"
  与"用 IP 画码"）。手机侧**不需要改动**：还是 App 里「扫码配对」。
- **入口与开关**：托盘菜单（状态 / 开关 / 复制地址）与应用菜单「手机访问」（窗口菜单栏沿用原
  `autoHideMenuBar: true`，按 `Alt` 唤出——用户看过成品后选择保持现状，日常用托盘）。
  开关与"用 IP 画码"偏好记在 `<userData>\mobile-access.json`。
- `app/src/preload.js` 暴露 6 个方法（状态 / 二维码 / 开关 / 用 IP / 复制 / 显示小窗）。

## 验证（都是实测，不是"看着对"）

隔离环境（独立端口 / userData / `DSH_HOME` 指向临时目录，不碰真实安装与 `~/.dsh`）：

- **打开即起**：真实 Electron 实例启动后，实测监听在尾网地址 `:8787`；
- **关掉即停**：`taskkill /PID <pid> /T /F` 后 8787 无监听、无孤儿进程；
- **中继确实在转发**：直连伪造 `Host`（尾网域名）→ **403**（被 `/api` 围栏拒）；经中继 →
  **401**（穿过围栏，仅缺 cookie）；未认证 WS 升级 → 立刻 **401**（不挂起）；连续 8 次
  暴力断连后中继仍存活；
- **二维码**：PNG 交 zxing 解码，与原文逐字符一致；小窗经 CDP 驱动**截图**确认渲染
  （曾发现一处 `style.display=''` 退回 CSS `display:none` 导致白框，已修）；
- **打包产物也测过**：`npm run build:dir` 的 `产出\win-unpacked` 同样起停正常、小窗正常。

## 已知 / 注意

- **本机（A机）用 agent 的受限环境启动 Electron 需要 `--no-sandbox`**，否则秒退
  （退出码 `0x80000003`）。这是环境限制，与产物无关：用户机器上安装版正常。
  连带后果：`npm run build:dir` 里带的打包冒烟在本机 [3]/[4] 会因环境报红，不代表产物坏。
- **`app/package.json` 的版本号由 CI 从 tag 同步**（`release.yml` 第一步），本地已同步到 0.3.8
  以免与已发布版本脱节。
- 提交纪律：本次只 `git add` 自己改的文件（未把工作区里他人未提交的 `AGENTS.md`/`CLAUDE.md`
  一起提交）。
