# 2026-08-23 桌面版不再自动打开系统浏览器

## 现象

每次桌面版新拉起 dsh 时，系统默认浏览器都会自动打开
`http://127.0.0.1:3080/`，与 Electron 窗口重复。

## 根因

`dsh web` 命令默认会在启动后调用系统浏览器打开 Web UI（可传
`--no-open` 关闭）。桌面版在 `app/src/main.js` spawn dsh 时未传该参数，
因此每次新实例都会多开一个浏览器标签页。

## 修复

`app/src/main.js` 的 spawn 参数追加 `--no-open`：桌面版自己已有窗口，
不再弹浏览器。

## 验证

- 重新打包（NSIS + portable + win-unpacked）成功，依赖守卫通过。
- 冒烟测试：启动新打包 exe，dsh 子进程命令行含 `web --port 3080 --no-open`，
  HTTP 200，清理后端口释放。
