- 调研 DSH 现状（作为访谈的事实基础）：
  - DSH = `@deepseek-ai/dsh` v0.1.0-rc.6，Node.js（ESM, Node 24）+ Cordis 4 插件体系。
  - CLI 入口 `dsh`：`--profile <name>`（web / headless / 自定义）、`dsh web`（web profile 别名）、`dsh plugin --profile <name>`（转发 pnpm 管理插件）。
  - Web profile 由 webserver + 前端静态资源 + apiproxy 等插件组合（`dsh-host-*`、`dsh-web-app`、`dsh-client-ui-*`），默认监听 `127.0.0.1:3080`。
  - 大量工具插件：bash/pwsh 终端、fs、subagent、workflow、goal、ralph、web、mcp-client 等（Node 原生能力为主）。
