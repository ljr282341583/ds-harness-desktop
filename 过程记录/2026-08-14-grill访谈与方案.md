## 关键修正（实测发现）

- DSH 依赖 Node 22.15+ 新 API（`node:zlib.createZstdDecompress`、`node:module.stripTypeScriptTypes`），
  Electron 33 自带 Node 20.18 跑不了。改为**捆绑独立 Node 24 侧车**（`app\runtime\node.exe`）运行 dsh。
- 打包随之改为 `asar:false`（侧车不识别 asar）+ `extraResources` 复制 `runtime/`。
- 顺带修了 error 页 `loadFile` 带 query 触发 `ERR_ABORTED` 的问题，改经 IPC 传错误信息。

## 打包结果（2026-08-14）

- 产物（`产出\`）：`DS Harness Desktop Setup 0.1.0.exe`（NSIS，220.6 MB）、
  `DS Harness Desktop-0.1.0-portable.exe`（220.4 MB）、`win-unpacked\`。
- 打包态冒烟测试通过：侧车 node 跑捆绑 dsh（195 个 `@deepseek-ai` 包），`waitForReady=true → loaded web UI`。
- 遇到并解决的问题：
  1. winCodeSign 7z 含符号链接，非管理员解压失败 → 设 `win.signAndEditExecutable: false`（v1 不签名，跳过）。
  2. electron-builder 的 `node-dep-tree` 对 DSH 依赖树裁剪不完整（195→9 个包，漏 peer 依赖）→
     加 `build\afterPack.js` 钩子，打包后用完整 `node_modules` 覆盖。
- 已知限制（v1）：未签名（SmartScreen 可能提示）；~~exe 未嵌自定义图标~~ ✅ 已补（见下）。
